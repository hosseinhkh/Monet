# Research memo — does Monet latent reasoning help a flow-matching action expert?

**Status: no results yet.** The GPU preflight (pipeline and correctness checks, not experiments) has
passed; no training run or evaluation has finished. This memo states the analysis plan before any result exists. Fill in

or null outcomes.

## 1. Question and hypotheses

Primary question: do Monet's genuine self-fed continuous latent states (K=10) improve closed-loop
LIBERO-Spatial success when they condition a compact flow-matching DiT, relative to a matched model without
latent steps (K=0)? Secondary question: is any gain worth its extra GPU time and latency?

* **H1 Feasibility.** D0/D1/D2 train stably and reach non-trivial LIBERO-Spatial success with the DiT.
* **H2 Added value.** D1 > D0 and/or D2 > D0 on held-out closed-loop success (primary contrasts), and D1 > D4
  (self-feedback rather than extra token passes).
* **H3 Dependence.** D3 interventions on D2 reduce success, with larger drops for content-destroying
  interventions (zero, gaussian, swap) than for mild ones (truncate:5). These are out-of-distribution
  perturbations, so the outcome shows dependence, not interpretability.
* **H4 Cost.** Report the quality vs GPU-seconds-per-success frontier; K=10 is "worth it" only if it lies on
  the frontier.

## 2. Pre-registered analysis

* **Unit of analysis.** One episode, identified by (seed, task, init state). The same keys are used for
  every variant, so all comparisons are paired.
* **Primary contrasts.**
  * D1 vs D0: frozen Monet, so K is the only difference.
  * D2 vs D0-LoRA: joint training with identical LoRA, budget and warm-start structure; K is the only
    difference.
  * D2 vs D0, as written in the original proposal, is also reported. It is labelled *confounded*,
    because LoRA adaptation of the VL features differs too.

  For each primary contrast, report:
  * the success difference with a paired bootstrap 95% CI;
  * the exact McNemar p-value;
  * per-task counts.
  With two primary contrasts, use Holm correction at α=0.05.
* **Secondary contrasts.** Each uses the same statistics:
  * D2 vs D1: the effect of LoRA;
  * D1 vs D4 and D2 vs D4-LoRA: self-feedback vs matched compute.
* **Power.** At 300 paired episodes, a true +5 pp gain is significant only 31–70% of the time and +8 pp
  67–100% of the time (see docs/BIG_PICTURE.md §4). Small effects require more episodes or training
  seeds before any claim.
* **Exploratory.**
  * K sweep {0, 5, 10, 20} (frozen Monet): report success and latency vs K. No multiplicity claims.
  * Latents-only conditioning.
  * TOOL_RESULT without the previous action (`d1_no_toolresult`). This checks whether the
    action-history input helps or causes copycat behaviour.
  * Bypass diagnostics on D2: `mask_vl` (latents only at test time) and `mask_all` (unconditioned head).
  * Latent layout: the default inference/RL layout vs the SFT-stage layout (`d1_sft_convention`).
    Monet-7B saw K=8 with the SFT layout and K=10 with the RL layout during training.
* **Effect size of interest.** A difference of at least +5 percentage points with a CI excluding 0. With
  300 paired episodes per variant, smaller effects may not be resolvable; say so explicitly rather than
  claiming "no effect".
* **Open-loop results.** Held-out FM loss and sampled-action MSE (fixed noise) are supporting evidence
  only.
* **Cost.**
  * Batch-1 latency p50/p95, split into Monet / DiT / preprocessing.
  * Amortised GPU-seconds per episode and per success.
  * Peak GPU memory.
  * Euler steps 2/4/8 on the best checkpoint.
* **Failure taxonomy.** Hand-label 10 failed videos per principal variant into: target localisation,
  gripper timing, wrong action frame, stalling, oscillation, latency.
